# 3L image handoff

The 3L site is intentionally wired to render without image binaries and automatically use them when they are added at these exact paths:

- `3l/assets/images/hero/dragon-bargain.png`
- `3l/assets/images/audio/audio-library.png`

The generated concept images from the 3L site workshop are intended for these two slots.

## Expected use

- `dragon-bargain.png` is the landing-page hero: older Greg deliberately facing an ancient dragon.
- `audio-library.png` is the Listening Archive image: a dark, warm-lit archive/listening chamber.

No HTML or CSS changes are required after the files are uploaded at those paths.
