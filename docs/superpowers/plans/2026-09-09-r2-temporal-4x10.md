# R2 Temporal 4×10 Experiment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce four concurrent ten-chapter R2 futures from accepted Chapter 42, each targeting roughly 30,000 words, then audit the resulting ~120,000 words for word count, engine behavior, prose, character, setting, plot, and action.

**Architecture:** All four horizons share only accepted truth through Chapter 42. A/B/C/D draft independently in interleaved rounds so future material does not become a single extrapolated conveyor. Nothing publishes automatically; the experiment ends in an audit and promotion recommendation.

**Tech Stack:** Markdown story files, GitHub branch isolation, exact connected reads, Python/local word-count verification if useful.

**Spec:** `docs/superpowers/specs/2026-09-09-r2-temporal-4x10-design.md`

## Global Constraints

- Work only on `experiment/r2-temporal-4x10-043-082`.
- Accepted R2 truth ends at Chapter 42 for first-draft purposes.
- Do not modify public reader/data/audio/image authority.
- A targets 43–52, B 53–62, C 63–72, D 73–82.
- Each horizon targets roughly 30,000 words; chapters aim around 3,000 words with 2,500–3,500 healthy variation.
- B/C/D do not inherit invented facts from nearer horizons during first draft.
- Greg's thought/action mismatch is allowed and desirable when character-grounded.
- Increase physical action and geographic/setting pressure without forcing spectacle.
- Future prose earns discovery, not authority.
