# PEG-LEG GREG — PROJECT BRAIN

This folder is durable shared working memory for Peg-Leg Greg.

Chats are workbenches. GitHub is the continuity spine.

The goal is not to preserve every thought. The goal is that a fresh worker can enter the repository, read a small number of files, understand the current project, do useful work, and leave the project easier for the next worker to continue.

## Authority order

1. Current authoritative manuscript prose
2. `state/MANUSCRIPT_STATE.md`
3. Explicit canon in `canon/`
4. Compact state in this folder
5. Handoffs and exploratory notes
6. Chat recollection

Newer authority beats older summaries. Manuscript prose beats project-memory paraphrase.

## Folder map

- `canon/` hard continuity and explicit canon
- `characters/` reusable character and relationship state
- `story/` current arcs, open threads, developmental direction
- `world/` places, institutions, economy, magic, ordinary systems
- `production/` reader, art, publishing, and workflow state
- `handoffs/` compact bridges between workers

## Memory standard

Save durable residue only:

- facts future workers need repeatedly
- current state that changes decisions
- unresolved questions worth carrying forward
- continuity risks
- evidence status
- decisions that should survive chat loss
- next useful edge

Do not save transcripts, giant chapter summaries, hidden reasoning, or speculative ideas without labels.

Use these labels where ambiguity matters:

- **ESTABLISHED** — manuscript or explicit canon supports it
- **STRONG INFERENCE** — evidence points here but does not prove it
- **POSSIBILITY** — useful developmental option, not canon
- **OPEN QUESTION** — intentionally unresolved

## Standard worker loop

READ REPO -> IDENTIFY LANE -> WORK -> VALIDATE -> UPDATE DURABLE STATE -> HANDOFF / RE-PROMPT

The next worker should be able to start from GitHub rather than requiring the same dedicated chat to survive forever.
