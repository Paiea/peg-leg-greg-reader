# Peg-Leg Greg Project Brain

This folder is the durable working memory for Peg-Leg Greg.

Chats, Codex sessions, and other work lanes should treat these files as shared project state. The running manuscript remains authoritative for prose and chapter canon. This folder stores compact, updateable knowledge about plot, characters, setting, world systems, unresolved questions, publishing, visuals, and active work.

## Authority order

1. Current running manuscript / shipped chapter files
2. Explicit canon recorded in `project_brain/canon/`
3. Compact state files in this folder
4. Chat discussion, exploratory notes, and old handoffs

When sources conflict, prefer the newer and more authoritative source. Do not overwrite newer manuscript work with stale summaries.

## Working rule

Read before writing. Update only durable residue, not transcripts.

Every substantial project lane should:

1. read the relevant project-brain files
2. inspect the newest manuscript/repository state when needed
3. do the work
4. update only the durable facts, decisions, open questions, and next edges that changed
5. avoid duplicating the same information across many files unless redundancy materially improves recovery

## Folder map

- `canon/` — explicit canon and continuity constraints
- `story/` — plot state, arcs, tensions, future possibilities
- `characters/` — character roster, relationships, development
- `world/` — setting, magic, institutions, geography, economics, culture
- `production/` — manuscript, reader, visual, publishing, and GitHub workflow state
- `handoffs/` — compact cross-lane handoffs when a task needs a stable bridge

Keep files compact enough that a new chat can read the relevant few files quickly.
