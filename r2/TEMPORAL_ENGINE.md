Status: **ACTIVE SPECULATIVE-DEVELOPMENT ROUTE**

- `do a year`;

- `jump ahead and see what happens`;
- `temporal experiment`;
- `future rehearsal`;
- `try six months`;
- `Gold party` / `more action` / `more tropes` as nudges on an active temporal run;
- `continue` when an active temporal experiment already has a durable run contract.

## Read

1. newest accepted R2 authority;
2. `r2/editorial/character-rebuild/TEMPORAL_ENGINE.md`;
3. the active experiment's `TEMPORAL_RUN.md` when one exists;
4. `r2/FUTURE_SURVIVOR_PROTOCOL.md` for promotion/re-performance boundaries;
5. only the exact story/state files needed for the current experimental edge.

## Required run inputs

Every substantial temporal run owns:

- one fictional **clock**;
- at least one meaningful **hard constraint or soft nudge**;
- an accepted-authority anchor;
- a stop condition.

Resolve missing inputs using the engine's rule:

**explicit user instruction → active run contract → high-confidence inference → one concise question only when material ambiguity remains.**

Do not make the user repeat inputs already stored in the active run contract.

## Authority

This route creates speculative development, not accepted story canon.

A finished temporal run does not publish itself. Useful survivors must reconcile against current authority and pass the normal Future Survivor / re-performance / selection path.

## Restart

A minimal valid continuation prompt is:

`Continue the active R2 temporal run from current GitHub authority.`

If the user adds a nudge, apply it to the active run contract at the smallest sensible scope and continue.
