About the second run

Greg has had two lives so far. So has his story.

R2 is not a patch on the first Peg-Leg Greg. It is another run, starting again with the lessons of the first one already in the room.

Run 1 mattered.

The original Peg-Leg Greg became a long, illustrated serial. It showed that the ordinary parts mattered: work, money, routes, relationships, physical limitations, tiny competence gains, and the residue left when enough time passes.

It also showed how much of Greg's life lived between the big events. People kept moving when he left the room. Time changed what was possible. The future remembered outcomes more cleanly than it remembered the people and mistakes that produced them.

So we start again.

R2 remembers those lessons without treating Run 1 as destiny. A person can make a different choice. A scene can take a different shape. Time can move differently. The second run only owes the first one memory, not obedience.

Each run remembers previous lives. It only has to live its own.

Built for the ear first.

R2 is shaped for listening from the beginning. Dialogue attribution, referents, movement, rhythm, and emotional beats need to stay clear even when there is no page to look back at.

The written rendition is not a transcript. It is a sister version of the same story, free to use paragraphs, silence, visual detail, and page rhythm where those help.

The pictures come from the same underneath.

Illustrations grow with the run. Characters, locations, props, and style accumulate visual memory as the story moves. The goal is not just more pictures. It is a book that increasingly looks like one world seen by one visual hand.

One story underneath.

Audio, writing, and images share the same scene reality. The world may contain more than Greg knows, but the story stays close to what he can perceive, infer, misunderstand, and care about. That shared core lets each format do what it is good at without becoming a competing version of what happened.
