# Chapter 249: The Wrong Copy

The seven-day archive job survived rain, toll law, charged stones, goats, and local insects.

Then Pel found the wrong receipt.

Not missing.

Wrong color.

The second village mayor had stamped the local copy instead of the city return copy.

Both contained the same words.

Only one belonged in the lockbox.

Pel stared at them as if paper had betrayed civilization.

"Can we use this one?" Kess asked.

"No."

"Why?"

"Because this one stays there."

"But it is here."

"Exactly."

We were already outside Carrow.

Pel sent a hired runner back with the local copy and a note containing no profanity but several sentences that wanted it.

I signed the Guild closeout.

Full pay.

No combat.

Kess asked whether all Silver work ended like this.

"Only the glamorous work."

Pel heard me.

"The records are dry."

"Very glamorous."

She checked them again...
