# R2 Temporal Writing Experiments

This directory contains disposable experimental evidence for temporal writing methods.

Nothing under this directory is accepted R2 story authority.

Experiment A remains separate under `r2/experiments/temporal-50/` and is not modified, continued, or reinterpreted here.

Experiment B lives under `b-distributed-prose/` and tests whether independently written speculative future prose can survive reconciliation well enough to increase accepted chapter throughput.
