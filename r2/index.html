Why run it again?

The first run taught us what the story wanted to be.

Peg-Leg Greg was written once already. R2 starts over with everything that first run taught us, without requiring the new story to follow the same path.

This run is built for listening first, then rendered into writing and images from the same story underneath. The point is not to erase Run 1. It is to let the second life remember the first and still become its own thing.
