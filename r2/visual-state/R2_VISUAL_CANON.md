# R2 VISUAL CANON

Compact current visual authority for Run 2.

This file is intentionally smaller than the Run 1 visual system. It records only what future image work should not have to rediscover.

## Authority boundary

R2 visual continuity is project-specific.

Run 1 artwork may be consulted as optional evidence, but it does not silently define R2 appearance, disability state, costume, location, or style.

Exact R2 story evidence outranks this file.

## Style

Current preferred family:

**sketch + ink + paint**

Key signals:

- visible drawing structure
- painterly wash
- rough, imperfect edges
- restrained sepia / charcoal / dirty-neutral palette with practical warm light when supported
- textured, lived-in surfaces
- selective detail rather than uniform hyper-detail
- illustrated-novel / print energy
- less polished and less generically cinematic than common AI fantasy art

The style should feel deliberately authored, not merely degraded to hide image-model mistakes.

## Greg — early R2

### Hard continuity

- age: 19
- clearly young
- both legs intact until story authority explicitly changes that state
- no peg leg, prosthetic, amputation, or crutches before canon establishes them

### Strong direction

- lean / underfed
- messy dark hair
- rough practical presentation
- light stubble is acceptable when he still reads nineteen
- sharp, watchful eyes
- intense rather than cheerful
- controlled danger
- calculating / predatory calm
- morally ambiguous
- can carry faint amused menace without becoming theatrical

### Avoid

- middle-aged Greg
- friendly tavern-hero smile as the default
- glossy romance-cover attractiveness
- oversized heroic physique
- obvious future disability leakage
- costume wealth/status that early story has not earned

## Carrow

### Core feel

Carrow is a working city before it is scenery.

Prefer:

- narrow urban routes
- stone / timber / worn plaster
- mud or wet cobble where supported
- carts, signs, shops, cheap rooms, guild traffic, labor, repairs, loading, trade
- visual evidence that ordinary people use the city
- dense practical architecture
- imperfect light and accumulated grime

### Avoid

- default harbor identity
- open-water skyline unless scene evidence requires it
- clean theme-park medieval streets
- giant fantasy towers used only to look epic
- empty streets that exist only as a character backdrop

## Cover / site art

R2 cover/frontdoor art may establish project mood but is not automatically character canon.

Useful evidence can be promoted from cover art only after explicit review.

## Current production principle

For early chapter art, prioritize continuity-establishing images and scene-specific anchors over broad coverage.

One strong Chapter 1 image that also improves Greg continuity is more valuable than several unrelated attractive panels.
