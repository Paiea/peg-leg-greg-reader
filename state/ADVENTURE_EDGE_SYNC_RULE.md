# PEG-LEG GREG — ADVENTURE EDGE SYNC RULE

This branch contains broad development guidance created while the live manuscript on `main` may continue advancing.

## Authority rule

Never treat chapter numbers cached in adventure-development files as manuscript authority.

Before using any near-edge adventure guidance:
1. read current `main` `state/MANUSCRIPT_STATE.md`;
2. inspect exact recent prose if a specific hook depends on current events;
3. treat older chapter-number references in development files as historical context only;
4. preserve newer canon and state over older branch assumptions.

As of this update, verified `main` authority is Chapter 352 — **THE COUNT**, but this number is deliberately not a permanent source of truth.

## Development rule

Adventure brains may hold durable principles, candidate structures, source quarries, trope permissions, and convergence tests.

They should not freeze:
- Greg's exact money;
- current magic counts;
- newest job access;
- current household state;
- latest chapter trailhead;
- whether a previously hypothetical outward seed has already happened.

Those facts always come from current manuscript authority.

## Practical implication

When a worker sees an adventure note saying `after 300`, read it as `after the established-normal phase` unless current canon still makes the literal number relevant.

Do not drag stale edge steering forward simply because the file survived.

The development architecture should compound while the story keeps moving.
