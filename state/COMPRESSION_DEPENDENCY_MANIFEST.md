# PEG-LEG GREG — COMPRESSION DEPENDENCY MANIFEST

Purpose: define the dependency evidence a structural-compression map must collect before MERGE or CUT can be approved.

## Core rule

A scene can be redundant in isolation and still be structurally necessary because later material depends on it.

Compression must preserve earned causality, not merely present-tense readability.

## Dependency categories

For every high-impact MERGE or CUT candidate, inspect and record relevant downstream dependencies in these categories:

### RELATIONSHIP
- later trust or intimacy assuming this scene happened;
- callbacks to embarrassment, favors, arguments, firsts, promises;
- changed forms of address, teasing, shorthand, touch, access, or authority.

### SOCIAL MEMORY
- running jokes;
- nicknames;
- group assumptions;
- unofficial roles;
- who remembers what;
- reputation spreading through a network.

### MONEY / MATERIAL STATE
- purse balance;
- debt movement;
- purchase price;
- item ownership;
- repair state;
- work/pay relationship;
- lodging/travel cost that affects a later choice.

### BODY / INJURY
- injury onset;
- recovery duration;
- equipment change;
- mobility adaptation;
- learned limitation;
- later behavior that assumes a physical experience occurred.

### MAGIC / EVIDENCE
- exact attempt counts;
- observed result;
- evidence-category change;
- apparatus/protocol continuity;
- uncertainty ceiling.

### OBJECT / PROVENANCE
- acquisition;
- mark/model;
- seller/source;
- repair/modification;
- custody;
- later use;
- later recognition based on provenance.

### WORK / OBLIGATION
- referral;
- contract;
- permission;
- debt/favor;
- reputation with employer;
- skill demonstrated to someone who later calls Greg.

### LOCATION / ROUTE
- first introduction;
- later shorthand/familiarity;
- travel time;
- route knowledge;
- accessibility constraint;
- social familiarity with place.

### ART / PUBLICATION
- approved illustration tied to scene;
- generated art prompt references;
- chapter-card or act-card use;
- public slug/link;
- site navigation/bookmark dependency.

## Manifest entry

Each proposed destructive structural action should have a compact dependency record:

- source chapter(s)
- proposed action
- surviving chapter destination
- relationship dependencies
- social-memory dependencies
- money/material dependencies
- body dependencies
- magic/evidence dependencies
- object/provenance dependencies
- work/obligation dependencies
- location/route dependencies
- art/publication dependencies
- later exact-text search hits
- unresolved risk
- disposition: preserve / relocate / intentionally retire / not applicable

## Search discipline

Search exact later manuscript for unusual names, phrases, objects, prices, nicknames, injuries, jobs, promises, and location names before high-impact cuts.

Do not rely on state summaries alone.

Absence of search hits does not prove a scene lacks emotional or atmospheric value.

## Approval rule

A CUT or high-impact MERGE should not move from map to execution while a material dependency remains listed as unresolved.

If preserving a dependency would require inventing new canon or materially changing a later chapter, escalate to author judgment.

## Goal

Compression should be able to remove redundant scene architecture while leaving the future manuscript feeling as though the surviving events genuinely happened and earned their residue.
