# PEG-LEG GREG — FIRST ADVENTURE CAST C

Non-canon candidate geometry for the first sustained outward adventure.

## Role

C is the person the original contract is about.

C should not function as an object to retrieve. The moment Greg reaches C, the mission should become more complicated because C has motives, obligations, relationships, and a version of events that does not match A's clean summary.

## Strong candidate shape

C left, remained away, or became unreachable for a reason that makes sense from C's position.

Possible reasons:
- unresolved conflict with A;
- refusal to return under old terms;
- an obligation in the current region;
- responsibility for someone or something A does not know about;
- shame / failure / debt;
- political or family pressure;
- fear of what returning will trigger;
- a local magical condition making departure dangerous;
- C did not realize how much their absence destabilized A's world.

C does not need to be innocent.

## Why Greg may like C

C should become a person Greg would plausibly choose to protect or at least hear out:
- competent in an ordinary lane;
- funny without sharing Greg's exact humor;
- generous in one specific way and selfish in another;
- good at something Greg respects;
- willing to admit at least one ugly truth;
- capable of making a bad decision for understandable reasons.

Greg should be able to understand why A wants C back and also understand why C may not want to go.

## Relationship with B

B initially arrives carrying A's assumptions and mission language.

C initially reads B as an extension of A.

The relationship becomes interesting when that assumption breaks.

Useful pressure:
- B learns A omitted something;
- C learns B is not simply A's instrument;
- B/C cooperate on a practical road/local problem before either trusts the other emotionally;
- one protects the other's dignity in front of Greg or locals;
- attraction emerges after mutual usefulness, irritation, and changed understanding.

## Relationship with A

A/C history should contain real tenderness or loyalty, not only ownership.

Possibilities:
- former lovers who never cleanly ended;
- intended / expected partners without a completed commitment;
- old companions whose intimacy became structurally important;
- family-linked relationship carrying social expectation;
- one saved the other's life and the debt became emotionally tangled;
- C promised to return and then did not.

The reader should be able to imagine a version where A and C could have worked under different conditions.

## Larger-world potential

C may carry the first truly strange category, but does not have to.

If C is unusual, keep the reveal downstream. Human conflict first.

Possible versions:
- C is tied to a regionally specific entity / ecology;
- C has a rare transformation capacity;
- C is protected by something dangerous;
- C crossed a boundary that changed what `return` means;
- C is not fully dead / alive / present in an ordinary sense;
- C has become responsible for a place or people in a way A cannot simply override.

## Failure mode to avoid

Do not make C the irresistible magical pretty person everyone desires.

C should earn attachment through personhood, history, and lived behavior.
