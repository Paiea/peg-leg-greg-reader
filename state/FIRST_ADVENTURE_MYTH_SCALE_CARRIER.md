# PEG-LEG GREG — FIRST ADVENTURE MYTH-SCALE CARRIER

Non-canon decision guide for where the first adventure's genuinely larger-world pressure should live.

## Core rule

Do not automatically make the romantic triangle itself supernatural.

The human relationship should work even if every magical layer is removed.

Then decide where one myth-scale pressure enters.

## Candidate carrier 1 — A carries it

A appears socially ordinary / merely powerful but possesses a rare body, inheritance, regional bond, or magical capacity that makes emotional escalation materially dangerous.

Strength:
- makes the return toward A increasingly tense;
- preserves the retrieval journey as human first;
- allows Greg to like A before understanding her full danger.

Risk:
- can too easily turn A into `jealous magical woman`.

Use only if A remains sympathetic and dangerous for reasons larger than jealousy.

## Candidate carrier 2 — C carries it

C has crossed into a category that changes what retrieval means.

Examples:
- rare transformation;
- bond to a local place / entity;
- protected or altered state;
- responsibility that cannot travel cleanly;
- technically living / dead / present status no longer simple.

Strength:
- finding C genuinely changes the contract;
- naturally converts retrieval into a different story.

Risk:
- C can become a magical object instead of a person.

## Candidate carrier 3 — The region carries it

None of A/B/C is secretly a mythic being.

The route / settlement / water system / old structure / local prohibition contains the category violation.

Strength:
- keeps the triangle human;
- makes the world itself larger than the cast;
- easiest way to use transformed moʻolelo without disguised deity mapping.

Examples:
- a water-associated guardian embedded in local life;
- disputed old construction that should not be possible;
- a prohibition Greg partly understands and partly misprices;
- a neutral entity no adventurer rank usefully describes.

This is currently the safest first-adventure option.

## Candidate carrier 4 — Someone adjacent carries it

A local ferryman, innkeeper, landholder, elder, merchant, hunter, or apparently ordinary woman is the strange one.

Strength:
- strongest decentering;
- Greg, A, B, and C are all standing near somebody else's much older story;
- rare shifters can remain genuinely rare.

This can create the desired feeling:

**Greg realizes the dangerous person was never the person he was hired to find.**

## Current preference

For the first major outward adventure, prefer:

1. **region / adjacent-person carrier**;
2. C carrier if it materially changes the retrieval question;
3. A carrier only if the story avoids flattening her into supernatural jealousy.

The first adventure does not need to reveal gods or define religion.

## Scale calibration

One major category violation is enough.

Greg can remain formidable while concluding:
- he does not know what rank applies;
- fighting would be stupid;
- survival and victory are different questions;
- the entity is neutral and should stay that way.

Do not immediately explain taxonomy afterward. Mystery is useful residue.
