# NOTEBOOK ENDING VARIANCE

Durable prose guardrail. Not canon.

## Problem
Greg's notes are a useful recurring device, but repeated chapter endings can become structurally predictable:

scene resolves -> Greg writes ledger / lesson -> crosses out neat phrase -> replaces it with a better phrase -> chapter closes on distilled meaning.

This can make otherwise different chapters feel authored from the same template.

## Rule
Greg's notebook is a character behavior, not a mandatory chapter-closing machine.

Do not automatically end a chapter with notes because money, work, magic evidence, or a lesson changed.

Use notes when Greg has a practical reason to preserve information, track money, record evidence, remember a term, or externalize something he genuinely would write.

## Vary endings
A chapter may instead end on:
- dialogue;
- an interrupted plan;
- food;
- somebody else leaving;
- a physical action;
- a small joke that remains unresolved;
- an image;
- a practical consequence;
- a new obligation;
- Greg choosing not to write anything;
- another person's reaction;
- ordinary silence.

## Cross-out limit
Crossing out an over-neat sentence can be funny and Greg-like, but it is now a recognizable pattern. Do not use it repeatedly as an anti-theme disclaimer.

If Greg writes something too neat, sometimes leave it. Sometimes do not write it. Sometimes notice the thought without recording it. Sometimes the note can be purely factual.

## Test
If the final page could be summarized as `Greg writes the chapter's thesis, rejects it, then writes the corrected thesis`, choose another ending unless that exact behavior is the emotional event.
