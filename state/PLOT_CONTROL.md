# PEG-LEG GREG — PLOT CONTROL

Durable plot/development memory. This file helps workers see story engines and promises without turning them into a rigid outline.

Use evidence labels:
- **ESTABLISHED** — manuscript fact
- **PRESSURE** — active unresolved force
- **POSSIBILITY** — useful future direction, non-canon
- **AVOID** — known bad/flattening direction

`MANUSCRIPT_STATE.md` remains the current-edge authority. `OPEN_THREADS.md` remains the compact unresolved-thread list.

## Theatre engine

**ESTABLISHED:** Greg is embedded in paid theatre work and continues learning through rehearsal, performance, stage geometry, corrections, mistakes, audience response, and ordinary company labor.

**PRESSURE:** competence is growing but remains uneven. Theatre must continue to be intrinsically worthwhile rather than merely instrumental.

**POSSIBILITY:** long-range theatre skills later become useful for misdirection/perception under pressure.

**AVOID:** obvious bluff-training arc; Greg dominating every performance; theatre becoming only plot utility.

## Long-range directional thread

**POSSIBILITY:** THEATRE -> PERFORMANCE -> MISDIRECTION -> ILLUSION -> MASKS -> CONTROL OF PERCEPTION -> EVENTUAL DANGEROUS BLUFF.

Desired eventual convergence:
- OLD GREG: real old-life knowledge / systems understanding
- SECOND-LIFE GREG: world limits / evidence / magic and institutional understanding

Do not schedule this prematurely.

## Engine rotation rule

A chapter does not need every engine. Track which engines have been foregrounded recently and allow others to breathe. Return because pressure or character naturally calls for them, not because a checklist says it is their turn.

## Plot workshop rule

When a development worker explores possibilities:
1. identify 1–3 highest-value tensions
2. actually develop at least one rather than only listing options
3. distinguish established fact from possibility
4. ask what changes for a person, relationship, job, or ordinary routine
5. prefer convergence between existing threads over disconnected machinery
6. leave durable residue here or in `OPEN_THREADS.md`, not a transcript
