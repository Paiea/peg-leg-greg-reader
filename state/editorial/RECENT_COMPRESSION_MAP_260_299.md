## Global diagnosis

The run contains strong material, but several chapter engines repeat too cleanly:

1. **ordinary errand / free morning -> interesting object or local system -> Greg asks -> local knows part -> Greg qualifies -> Greg leaves -> Greg explains why he did not overreach**;
2. **bounded paid question -> scope negotiation -> compare object(s) -> Greg says what he knows and does not -> one copper -> Greg writes a rule about capital/client work**;
3. **Hessa protocol -> full body/setup recap -> expectations -> attempt -> Hessa checks -> Greg asks what can be claimed -> explicit lesson about restraint**;
4. repeated `this was growth`, `not my job`, `not a profession`, `not a project`, `good`, `maybe`, `that mattered`, and explicit narration explaining a boundary the scene already proved;
5. practical workers increasingly using Hessa-like qualification rhetoric instead of domain-shaped speech;
6. repeated unchanged body/equipment checklists after the reader already understands Greg's baseline.

The fix is **not** to remove quiet life. The fix is to stop giving every quiet observation the same four-thousand-word architecture.

## Structural north star for this window

Protect the distinct movement:

**Greg becomes useful in more places -> attention acquires value -> Greg learns scope / money / limits -> magical life becomes ordinary infrastructure/ecology -> Greg begins choosing participation even when nobody needs him.**

Late-run leisure and belonging chapters are not filler. They are payoff for earlier work.
