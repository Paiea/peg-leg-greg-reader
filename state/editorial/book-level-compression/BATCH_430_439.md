## Sequence-level diagnosis

The recent manuscript repeatedly uses a strong but increasingly visible grammar:

local infrastructure problem -> multiple competent stakeholders -> bounded authority -> Greg refuses overclaim -> distributed expertise narrows problem -> operational result -> Greg records lesson -> body/money/tool state updates.

This grammar is good PLG.

The problem is that Chapters 430-437 deploy versions of it close enough together that chapter boundaries begin preserving generation units instead of book units.

The correct edit is not to remove mundane life or competent institutions. It is to concentrate each distinct experience around its strongest value.
