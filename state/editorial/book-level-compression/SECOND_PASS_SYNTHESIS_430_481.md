# REPEATED DELIVERY MACHINERY TO TARGET DURING LATER SURGERY

These are cross-chapter patterns, not automatic deletion rules.

## 1. Institutional ambiguity scene

Repeated shape:

professional A has one authority -> professional B has another -> evidence conflicts -> Greg refuses overclaim -> local procedure creates bounded solution -> narration explains why this is good.

Keep the strongest examples. Later examples need a new consequence or should shrink.

## 2. Instrument humility lesson

Repeated shape:

interesting device -> apparently simple interpretation -> specialist narrows claim -> another instrument/context is required -> Greg admires bounded evidence.

After the reader understands this worldview, later chapters should trust them more.

## 3. Body log

Repeated shape:

wear duration -> fatigue time -> warmth/pink -> removal -> 20/30-minute clear -> lesson.

Preserve only when terrain, task, gait, hand freedom, injury, or fit decision changes.

## 4. Money ceremony

Repeated shape:

count cash -> subtract fare/lodging -> restate 10c floor -> interpret number emotionally -> later recount.

Keep arithmetic required for canon. Reduce ceremony when behavior does not change.

## 5. Notebook theorem

Repeated shape:

scene happens -> Greg writes exact observation -> adds `what this means` -> adds `what this does not mean` -> derives broader support principle.

Notebook is character texture. The explanatory layer is overused.

## 6. Route-board chapter engine

Repeated shape:

arrive -> lodging board -> work board -> route board -> choose small job -> earn -> buy next ticket.

This should progressively become background literacy as Greg becomes more experienced.

## 7. Repeated restraint proof

Greg does not need to prove in every chapter that he will:

- avoid touching specialist equipment
- avoid claiming authority
- avoid using magic unnecessarily
- avoid buying the shiny thing
- avoid lifting what his body should not lift

When established behavior persists, use fewer words unless temptation or consequence is genuinely new.

## 8. Closing thesis

Cut aggressively when the final paragraph explains an image, joke, decision, or relationship beat that already landed.

The strongest PLG endings often stop one paragraph earlier.
