- separates possession, curse, memory ownership, age, and mechanism;
- allows herself anger and disbelief;
- then returns to the one thing she can verify immediately: Greg's present Barrier;
- identifies the practical magical problem as Greg giving a nineteen-year-old body instructions from a body it is not.

This is a major character/canon scene. Do not use a future dialogue pass to "improve" it by adding more explanation.
