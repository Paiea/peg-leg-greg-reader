`current authoritative prose -> dramatic structure -> PERFORMANCE -> explicit script -> PLG prose -> attribution / continuity / Showcase seam validation`

## Round-trip rule

A chapter does not need to change merely because it passed through the intermediate representation. The script must expose a concrete performance failure that survives translation back to first-person Greg prose. If the source already performs the dramatic structure more naturally than the explicit script, source wins.

The explicit script stage is therefore an intervention surface, not a rewrite quota.

## Explicit script evidence for surviving changes

The script layer is intentionally terse. Greg's interior narration is kept as a separate channel so another character's behavior is not silently converted into Greg-shaped interpretation.

### Canon 007, Antonius storeroom

- GREG WANT: identify and capture the value of the gray precision object.
- ANTONIUS WANT: clear the storeroom and decide whether an object belongs in keep, sell, or discard.
- ACTIVE TASK: Antonius is physically sorting and cleaning.
- PRESSURE: Greg recognizes future value before he has a current buyer or proof.
- PERFORMANCE RULE: Antonius does not need to win Greg's joke. He continues work until Greg gives information that changes the decision.

Script:

```text
ANTONIUS [moves box toward discard]: Trash.
GREG INTERNAL: Say nothing. Ask for the trash later. Free is an excellent price.
GREG: That is potentially extremely valuable.
ANTONIUS [stops, returns, picks up frame]: How valuable?
GREG INTERNAL: Fuck.
```

Round trip: survives. The resulting prose keeps Antonius in cleanup mode until Greg earns an attention shift.
