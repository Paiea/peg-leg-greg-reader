## Main judgment

The 70-chapter sample does **not** support a global conclusion that PLG's short sentences are a problem.

Short units are frequently doing useful work in:

- comedy and punchline timing;
- physical action and impact;
- injury, pain, and medical decision-making;
- crutch and stair learning where each contact is a real bodily beat;
- uncertainty and self-correction;
- dialogue handoffs;
- realization or deliberate stopping.

The repeatable weaker pattern is narrower: Greg sometimes turns **one analytical movement** into several visual sentence or fragment boundaries. The strongest candidates occur in technical possibility inventories, application lists, and branching theory trees. These passages often read faster when the list becomes one shaped sentence while the actual turn, joke, correction, or stop remains short.

This supports **semantic recomposition**, not generic prose lengthening.

## Routing conclusion

The useful routing rule after this sample is:

1. If adjacent short units are separate physical, comic, emotional, dialogic, or realization beats, **KEEP SHORT**.
2. If they are one uninterrupted analytical list, causal model, or option tree, **RECOMPOSE** before deleting anything.
3. Only after recomposition, remove meaning that is genuinely repeated, **COMPRESS**.
4. If the benefit is unclear, **NO CHANGE**.

The strongest leverage target for future batches is therefore not `short sentence density`. It is **unnecessary semantic boundary density inside analytical prose**.
