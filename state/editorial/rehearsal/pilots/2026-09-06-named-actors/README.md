## Result

The named-actor layer produced useful differences, but not mainly through catchphrases or larger dialogue rewrites.

The strongest identity separation came through **behavioral ownership**:

- Desmond/Antonius keeps working until information changes the transaction, then uses object placement, shelving, labeling, and return-to-task behavior as authority.
- Rowan/Arlo protects process through the notebook, fixtures, failed regulators, readings, and next-test choices instead of becoming a polished exposition engine.
- Mara/Hessa expresses boundaries through procedure and object control: place, repeat, narrow, cover, count, stop.
- Nico/Greg owns the strongest comic compression and the tendency for system-recognition excitement to outrun strategic restraint before self-correction.

This is the intended REHEARSAL direction: different characters should not merely receive different sentence-length settings. They should **do different things under pressure**.
