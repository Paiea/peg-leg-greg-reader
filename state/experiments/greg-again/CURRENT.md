## Shared Greg Surface

The Shared Greg Surface should already be:

- nearly publishable as prose
- nearly speakable as audio
- Greg-dominant when that remains the most interesting lens
- clear about who acts, knows, chooses, refuses, promises, prices, threatens, or changes state
- embodied rather than summarized
- capable of fragments, resets, and self-correction only when cognition actually moves that way

It carries the discoveries that belong to Greg rather than to a medium:

- Greg-dominant continuity
- attention gravity
- selective direct speech
- earned voice breaches
- embodied outside characters
- associative thought
- action interrupting analysis
- language-as-action
- thoughts that bunch, stop, redirect, or vanish according to pressure

## Routing test

For every proposed change, ask:

> **Did we learn something about Greg's experience, or only about the medium?**

If the discovery is about Greg, move it upstream into the Shared Greg Surface so both page and ear inherit it.

If it only solves a listening problem, keep it audio-only.

If it only solves a reading problem, keep it written-only.

Do not use a lexical-overlap quota. Use the stronger rule:

> **Differences require a medium reason.**

## Audio posture

Audio finish is now **repair-first**, not performance-decoration-first.

Default assumption:

> **Read the Shared Greg Surface substantially as written unless listening exposes a specific failure.**

Audio may intervene for:

- syntax that is difficult to understand in one pass
- speaker or referent ambiguity
- movement or causal order that becomes unclear without a page
- an interruption that does not register audibly
- an important pause being steamrolled
- a sentence whose visual punctuation does not create the intended spoken relationship

Audio may split, simplify, or lightly reshape when the ear earns it.

Do **not** automatically add:

- `Right.`
- `Fine.`
- `Probably.`
- `Again.`
- repeated words
- self-corrections
- isolated fragments
- uniform breath-sized segmentation

merely to make synthesis feel performed.

> **Do not write tics for performance.**

## Written posture

Written finish is also intended to remain small.

The page may:

- recombine visually fussy fragments
- tune punctuation and paragraph architecture
- use a denser sentence when rereading makes it stronger
- remove an audio-only repair that looks artificial
- preserve isolated lines when the cognitive pause matters visually too

Do not clean the spoken character out of the prose merely because the page can support more conventional syntax.

> **Clean performance residue. Do not clean away cognition.**

## Listening evidence: A / B / C

A short Chapter 2 training-yard passage was rendered with the same voice/software in three forms.

### A — conventional / LIGHT-ish

More conventional first-person prose and dialogue ownership.

### B — Greg-dominant page-native surface

Selected written Greg-dominant prose, read essentially as written.

### C — deliberately audio-shaped

The Greg-dominant material received more explicit breath segmentation, resets, isolated fragments, and spoken shaping.

Listener preference in this sample:

> **B over C.**

The useful complaint about C was that it sounded **too smooth** despite looking more fragmented. The added segmentation did not create stronger cognitive pauses.

Surviving interpretation:

> **Pauses come from contrast, not fragmentation.**

Thought does not move in uniformly spaced audiobook beats. Some ideas bunch together. Some stop. Some interrupt. Some receive space because the surrounding flow did not.

If everything is isolated, isolation stops carrying meaning.

This is strong enough to change the default, not strong enough to ban later audio shaping across all scene types.

## Current lens prior

Chapter 2's useful earlier result still survives:

> **GREG-DOMINANT beats both LIGHT-ish and EXTREME for the tested training / bureaucracy material.**

EXTREME taught that Greg can carry much more linguistic continuity than conventional prose assumes.

GREG-DOMINANT corrected the boundary:

> **Other people's exact language should break through when the wording itself carries character, leverage, humor, falsification, relationship movement, or a binding state change.**

Zero dialogue is not a target.

## Outside-character rule

Do not turn supporting characters into summaries or NPCs.

Do not replace embodied scenes with `Sella explained the rules` or `Jorren told me what to do` when hands, movement, timing, leverage, refusal, objects, mistakes, and consequence can keep the other person alive.

> **Remove transcript, not embodiment.**

Greg owns continuity, not reality.

## Language can be action

Prices, promises, threats, wagers, contracts, consent, refusal, deadlines, orders, names unexpectedly revealed, and negotiated terms can change story state merely by being spoken and accepted.

A Greg-dominant surface may compress conversational plumbing.

It may not make binding commitments fuzzy.

## Anti-tic rule

Greg's recurring language is valid only when it reflects an actual cognitive move.

Watch for generated texture built from:

- `Right.`
- `Fine.`
- `No.`
- `Wait.`
- `Of course.`
- `Apparently.`
- one-line fragments
- repeated self-correction
- every observation becoming a dry punchline

If removing half the tics changes nothing about Greg's thinking, the surface is imitating Greg rather than rendering him.

The listen test strengthens this rule. There is no longer a medium excuse for adding a tic merely to improve synthetic narration.

## Current acceptance test

Ask:

1. Is Greg more compelling to inhabit?
2. Do thoughts move according to salience rather than a repeated cadence template?
3. Do supporting characters remain causally independent and behaviorally legible?
4. Does direct speech become more valuable because it is selective rather than merely rarer?
5. Can the shared surface survive both page and ear without a rewrite?
6. If audio changes wording, is there a specific audible reason?
7. If written changes wording, is there a specific page reason?
8. Are binding terms, refusals, promises, threats, and negotiated state changes unambiguous?
9. Does the reader/listener attend to Greg and the story rather than the renderer or synthetic voice?

## Promotion discipline

One short listen test does not settle every scene class.

The new default is justified because it also agrees with existing written evidence and the earlier anti-tic / page-native findings.

Retest stronger audio shaping only when a materially different scene earns the cost, especially:

- dense multi-character interaction
- high-emotion confrontation
- intimacy
- complicated spatial action
- scenes with difficult speaker attribution

Do not generate alternate surfaces by quota.

## Current operating shorthand

> **WRITE GREG CORRECTLY FIRST. DO NOT ADD FAKE GREG AFTERWARD.**

> **GOOD GREG PROSE IS THE DEFAULT SHARED SURFACE.**

> **AUDIO REPAIRS AUDIBLE FAILURES. WRITTEN REPAIRS PAGE FAILURES.**

> **PAUSES COME FROM CONTRAST, NOT FRAGMENTATION.**

No canon promotion is implied by this experiment.
