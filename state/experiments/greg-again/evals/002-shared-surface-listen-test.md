# Chapter 2 — Shared Greg Surface Listen Test

Status: **USEFUL SIGNAL / NOT LOCKED DOCTRINE**

Purpose: isolate where the audible improvement actually comes from.

One short training-yard passage from Chapter 2 was rendered through the same `deep` voice/software in three forms:

## A — conventional / LIGHT-ish surface

More conventional first-person prose and dialogue ownership.

This tests the baseline before the Greg-dominant surface does substantial work.

## B — Greg-dominant page-native surface

The selected written Chapter 2 surface was read essentially as written.

It preserves:

- Greg-dominant continuity
- natural paragraph contrast
- fragments only where cognition actually fragments
- selective direct speech
- compressed routine dialogue
- associative thought runs

No extra audiobook tics were deliberately added.

## C — deliberately audio-shaped surface

The same Greg-dominant material received more explicit spoken shaping:

- more breath-sized line breaks
- more isolated fragments
- added resets / self-corrections
- more uniform spoken segmentation

## Listener result

**B was preferred over C in this sample.**

The important complaint about C was not lack of clarity. It was that C became **too smooth** and did not create enough meaningful pauses despite looking more fragmented on the page.

B felt closer to how thought actually moves and processes: some ideas bunch together, some interrupt, some stop, and some receive real space.

## Surviving learning

### 1. Greg-dominant is not an audio trick

The large gain appears to come from the underlying narrative surface: Greg owning continuity, attention moving naturally, and outside language breaching selectively.

Treat those as **Greg Experience** discoveries shared by page and ear.

### 2. Do not write tics for performance

`Right.`, `Fine.`, `Probably.`, `Again.`, self-corrections, repeated words, and isolated fragments survive only when they represent an actual cognitive move.

Do not add them merely to make TTS sound performed.

> **WRITE GREG CORRECTLY FIRST. DO NOT ADD FAKE GREG AFTERWARD.**

### 3. Pauses come from contrast, not fragmentation

Uniformly splitting prose into short units can cause synthesis to flatten the hierarchy of thought rather than strengthen it.

Useful pause contrast can come from:

- sentence-length variation
- paragraph architecture
- punctuation
- action interrupting thought
- one genuinely isolated line among normal flow
- another character taking linguistic space at the right moment

If everything is isolated, isolation stops carrying meaning.

### 4. Audio finish becomes repair-first

Default assumption:

> **The shared Greg surface survives into audio unchanged unless listening reveals a specific audible failure.**

Audio-only intervention is earned by problems such as:

- syntax that cannot be understood in one pass
- an interruption that is not audible
- unclear speaker / referent
- a necessary pause being steamrolled
- spatial or causal sequencing becoming confusing without the page

Do not manufacture generic `audiobookiness`.

### 5. Written finish remains small too

Page finish may recombine visually fussy breath fragments, tune punctuation, or use page-specific paragraph rhythm.

Do not clean away cognition merely because it originated in a surface that also speaks well.

## Current shared model

```text
STORY / PERFORMANCE
        ↓
   GREG EXPERIENCE
        ↓
 SHARED GREG SURFACE
      ↙       ↘
AUDIO REPAIR   WRITTEN FINISH
```

The Shared Greg Surface should be nearly publishable and nearly speakable by default.

Do not enforce a lexical-overlap percentage. Use the stronger rule:

> **Differences require a medium reason.**

A discovery about Greg moves upstream and should reach both media.

A discovery only about the ear stays audio-only.

A discovery only about the eye stays written-only.

## Confidence

Strong enough to change the default posture.

Not strong enough to claim every scene type will prefer B over additional audio shaping.

Retest on materially different scenes only when useful, especially high-emotion dialogue, dense action, or multi-character sequences.
