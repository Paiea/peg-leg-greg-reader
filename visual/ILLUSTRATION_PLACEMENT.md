# Illustration Placement Manifest

This file is the durable source for where generated/promoted chapter art belongs in the prose. An image is not production-ready until its placement is recorded here.

## Placement syntax
Each slot records:
- chapter and exact title
- slot number
- insertion anchor: exact nearby prose phrase or paragraph description
- scene content
- required continuity
- forbidden content
- production asset path once accepted
- status: PLANNED / GENERATED / ACCEPTED / PROMOTED / LIVE
